PRACTICAL LEARNING

Health and agricultural datasets

The datasets are simulated for teaching. They are not real patient records or farm observations.

Health screening dataset

Age, sex, BMI, systolic and diastolic blood pressure, fasting glucose and screening indicators. Use it for frequencies, descriptive statistics, t-tests, chi-square and correlation.

Agriculture field-trial dataset

Maize variety, fertilizer, rainfall, soil pH, soil nitrogen, disease presence and yield. Use it for descriptive statistics, ANOVA, correlation and regression.

SPSS 27 syntax files

Download syntax examples for both subject areas. Open the .sps file in the SPSS Syntax Editor and select Run → All.

SPSS 27 note: Menu wording can vary slightly by installation. The lessons identify the standard SPSS Statistics 27 menu path and provide equivalent syntax. This website teaches SPSS; it does not execute IBM SPSS inside the browser.

LEARNING RECORDS

Progress and repeat learning

Students can revisit any lesson and repeat any quiz. The monitoring workbook records each submitted activity, including the date, student identifier, module, lesson or quiz, score and attempt number.

For students: there is no account, password, attempt limit or lockout.

For the lecturer: the monitoring spreadsheet is private to the account that created it. Use the spreadsheet to review quiz attempts and practical submissions, then enter feedback and marks in the lecturer columns.

The monitoring workbook must not be shared publicly because it contains student names, registration numbers, email addresses and submitted work.
